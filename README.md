# BookingEngine
### aplikacja do zarządzania rejestracjami salek konferencyjnych

## MVP
Aplikacja powinna:

- umożliwiać dodawanie/usuwanie użytkowników
- umożliwiać dodawanie/usuwanie/edycje pokojów, cen, budynków, itd.
- umożliwiać dodawanie/usuwanie/automatyczne usuwanie rejestracji

- logowanie uzytkownikow
- sprawdzanie statusu rejestracji
- sprawdzanie kalendarzowe dostepnosci pokojów
